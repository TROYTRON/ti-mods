# Tutorial resources

These are supporting files, not a single installable mod. Follow the linked guide before copying anything into Terra Invicta.

| File | Purpose |
| --- | --- |
| [CreateAssetBundles.cs](CreateAssetBundles.cs) | Unity 2020.3.49f1 Windows x86_64 bundle helper; put in `Assets/Editor`. [Workflow](../../docs/assets.md) |
| [Terra Invicta Badge Maker.psd](Terra%20Invicta%20Badge%20Maker.psd) | Layered badge template from the portrait guide |
| [Badge guide PNG](Terra%20Invicta%20Badge%20guide.png), [badge border PNG](Terra%20Invicta%20Badge%20border.png) | Badge placement and border references; [portrait workflow](../Councillor%20Portraits.md) |
| [Template JSON examples](template-json-mod-examples/Template%20JSON%20Mod%20Examples.md) | Native metadata and bilateral-template examples |
| [MonoMod ship framework](TIShipModdingFramework_MonoMod.cs) | Tayta's adaptation of Razorback's framework; [compatibility and prefab guidance](../../docs/assets.md#inspect-assets-and-ship-examples) |
| [Unity object tree](uniuty_object_tree.png), [ship designer tree](ship_designer_object_tree.png), [expanded Titan](larger_titan.png) | Illustrations for the [worked UI example](../Ship%20Designer%20UI.md) |

For FMOD, use the package shipped in the game's `TerraInvicta_Data/StreamingAssets/ModdingTools` directory; follow [Stallion's audio workflow](../Audio%20Modding%20Guide.md). Ship examples are maintained in [UNNRazorback's TIShipModdingFramework](https://github.com/UNNRazorback/TIShipModdingFramework).
